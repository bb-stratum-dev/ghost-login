# 👻 ghost-login

> **A minimal, zero-backend authentication sandbox featuring FastAPI-inspired glassmorphism, responsive UI, and a playful auto-logout sequence.**

---

### 💡 Overview

**ghost-login** is a lightweight, single-file web application built by **bb-stratum-dev**. 

It provides an interactive, client-side simulation of a modern FastAPI-styled login interface with smooth glassmorphism effects, rounded inputs, and crisp micro-interactions. Operating on a strict zero-data-persistence policy, it confirms your login attempt, displays a friendly farewell animation, and automatically logs you back out.

---

### ✨ Highlights

* 🎨 **Modern Glassmorphism:** Custom CSS backdrop filters, smooth gradients, and rounded UI components.
* ⚡ **100% Client-Side:** Pure HTML5, CSS3, and JavaScript with zero external dependencies, databases, or tracking.
* 👻 **Playful Auto-Logout:** Displays an animated farewell sequence immediately after successful authentication.
* 📱 **Fully Responsive:** Styled for single-screen viewability on both mobile and desktop displays.
